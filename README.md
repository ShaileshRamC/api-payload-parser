# Generic Webhook Validator

A lightweight, open-source Express/TypeScript utility designed to catch, validate, and inspect incoming webhook payloads during API integration testing. 

## Why this is useful
When building multi-step API integrations or testing conversational AI platforms, developers need a reliable way to inspect outbound payloads without setting up complex backend infrastructure. This listener provides an immediate endpoint to verify JSON structures, catch formatting errors, and ensure seamless data flow before routing payloads to production databases.
